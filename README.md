# Industrial Intelligence — Alagoas

> Streamlit dashboard for exploring the industrial company universe, sector classification and commercial opportunity signals in Alagoas.

**Portfolio focus:** Market Intelligence · Data Analytics · Segmentation · Streamlit · Commercial Decision Support

## Purpose

The application organizes company-level industrial information into an analytical view for market sizing, segmentation and commercial opportunity discovery.

## Analytical Flow

`Industrial Company Base → Data Preparation → CNAE / Sector Classification → Relationship & Eligibility Signals → Dashboard`

The dashboard works with company attributes such as:

- sector;
- CNAE;
- company size;
- municipality;
- SESI/SENAI relationship indicators;
- SEBRAE eligibility;
- commercial opportunity.

## Technology Stack

Python · Pandas · Streamlit · Excel · Data Visualization

## Data Governance

The repository contains company-level data files. Before using this project as a public portfolio artifact, sensitive or identifying records should be replaced with synthetic, anonymized or aggregated data.

## Portfolio Perspective

This project represents the **market-intelligence layer** connecting company data to segmentation and commercial analysis.
